# 正文质量修复计划

用户已确认：修正写作输入、记忆语义、章节边界及有证据的局部修稿。保留作品数据与现有工作区改动。

1. 写作与审查使用作品的视角、基调和 style_note；风格模板只补充未指定要求。空认知、关系记录表示未知，不表示无秘密或初见。
2. 有前文或本章续写内容时，正文生成前通过 planning 模型核对本章计划与已写事件，输出带原文证据的边界说明；无历史的开篇不额外调用。证据不匹配时停止，不把臆测当事实。
3. 沿用审查报告中的局部修改预览。采纳时在服务端校验报告新鲜度、当前正文及原句唯一匹配，保存新版本，再自动复核。可疑问题不自动采纳。审查同时给出少量具体删冗建议，但不得将文学偏好判为事实错误。
4. 用隔离数据库和模拟模型测试提示传递、边界检查、证据拒绝、版本保留及旧报告拒绝；运行后端回归和前端构建。不调用真实模型，不写用户数据库。

验收边界：测试验证流程和数据契约，不宣称真实模型输出已经达到文学质量目标。
